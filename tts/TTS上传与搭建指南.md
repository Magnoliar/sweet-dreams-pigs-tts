# 《猪你好梦》Tabletop Simulator (TTS) 一键存档与上传指南

本目录 (`tts/`) 已内置 **一键可导入的 TTS 模组存档**（含全套 97 张卡牌、主棋盘 57 个精确吸附点、6 只双面小猪、30 枚呼噜筹码、小木碗、6 张毛毡小被子、PDF 规则书与完整 Lua 自动化脚本），无需手动拼装即可直接开玩！

---

## 一、快速本地试玩（1 分钟一键导入）

1. 将以下两个文件复制到 TTS 本地存档目录：
   - `tts/猪你好梦_TTS模组存档.json`
   - `tts/猪你好梦_TTS存档缩略图.png`
   - 目标路径（Windows）：
     ```text
     %USERPROFILE%\Documents\My Games\Tabletop Simulator\Saves\
     ```
2. 启动 **Tabletop Simulator** -> `Create` -> `Singleplayer / Multiplayer` -> **`Games -> Save & Load`**。
3. 在存档列表中找到带封面的 **`《猪你好梦》Sweet Dreams, Little Pigs!`**，点击 **Load** 即可直接开局！

> 💡 **提示**：本地存档默认使用本机 `file:///` 路径加载 `tts/` 与 `print/` 素材，仅限本机单人测试；如需好友联机或上传创意工坊（Steam Workshop），请看第二节。

---

## 二、上传 Steam 创意工坊（联机 / Workshop 发布）

联机玩家需要从公网 HTTPS 地址加载图片与 PDF。可使用内置工具 **`tts/patch_urls.py`** 一键替换所有本地路径：

### 方法 A：使用 GitHub / CDN 公共仓库地址
1. 将本仓库（至少包含 `tts/` 和 `print/《猪你好梦》规则说明书_A5排版.pdf`）推送到公开仓库或图床。
2. 运行命令一键替换存档中的全部 URL：
   ```bash
   python tts/patch_urls.py https://raw.githubusercontent.com/<用户名>/<仓库名>/main
   ```
   （如仅想输出新文件而不覆盖原存档，可加 `--output tts/猪你好梦_Workshop存档.json`。）

### 方法 B：使用 Steam Cloud 映射表
1. 先查看存档中引用的全部 15 个本地素材路径：
   ```bash
   python tts/patch_urls.py --list
   ```
2. 在 TTS 内通过 `Modding -> Cloud Manager` 上传 `tts/` 中的图片后，将文件名与对应 Steam Cloud URL 写成 `urls_mapping.json`（例如 `{"00_通用卡背_CardBack.png": "https://steamusercontent-a.akamaihd.net/..."}`），执行：
   ```bash
   python tts/patch_urls.py urls_mapping.json
   ```
3. 在 TTS 中 Load 替换好公网 URL 的存档，点击 **`Modding -> Workshop -> Upload`** 即可发布到 Steam 创意工坊！

## 三、桌面 Lua 自动化控制面板与操作视角说明

屏幕右侧已内置 **2D 高清悬浮助手 (`猪你好梦 助手`)**（不受 3D 镜头缩放影响，支持点击右上角 **`收起 / 展开`** 折叠为小标签），同时棋盘右侧也保留了一块 **`《猪你好梦》控制面板`**，两者状态实时同步，支持以下一键自动化操作：

| 按钮 | 功能说明 |
| :--- | :--- |
| **`[开局] 一键开局 / 重置`** | 洗匀集市牌堆并翻开 5 张（若屋规区为《今夜小集市》则翻 6 张）；洗匀粉/黄初始牌库，自动发 **粉方 4 张、黄方 5 张**；6 只小猪归位地板并翻回清醒；双方美梦分归 `0`；收回被子与呼噜筹码。 |
| **`粉猪睡醒摘星` / `黄猪睡醒摘星`** | 自动扫描中央 `3×3` 睡毯上的己方**熟睡小猪**（每只 `+1星`）与**正交贴贴对数**（每对 `+1星`），自动沿 `0–15` 分轨移动计分标记，将熟睡小猪翻回清醒，并把盖在猪身上的毛毡小被子收回供应区。 |
| **`粉猪算呼噜` / `黄猪算呼噜`** | 自动扫描己方**出牌区**：<br>• 正放正面牌 ➔ 累加牌面 `云`<br>• 横置（旋转约 90°）正面牌 ➔ 跳过执行（`0云`）<br>• 背面朝上盖牌 ➔ 累加助梦 `云`（`1` 或 `2`）<br>同时计入 `3×3` 睡毯己方熟睡猪（`+1云/只`）及中央枕头格奖励（`+1云`，若启用《软绵大枕头》则 `+2云`），并自动从供应区向小木碗拨入对应数量的 `1云` 筹码！ |
| **`粉猪结束回合` / `黄猪结束回合`** | 清空小木碗中的呼噜筹码回供应区，将出牌区卡牌移入弃牌堆，自动**摸 5 张牌**（牌库不足时自动将弃牌堆翻面洗匀后补抽），并自动补齐集市展示区空位。 |
| **`+1分` / `-1分`** | 手动微调粉/黄美梦分（用于《搬大南瓜》《全家团圆》《毯角藏星星》等卡牌/屋规额外得分），计分标记会同步在分轨上移动。 |

> 💡 **小贴士（视角与操作）**：
> - **快捷视角**：按 **`Shift+1` ~ `Shift+4`** 可一键切换预设视角（`1` 全景总览、`2` 主棋盘特写、`3` 控制面板特写、`4` 集市与屋规区），按数字 **`1`~`4`** 即可恢复对应视角。
> - **平移与看牌**：使用 **`WASD`** 或按住 **`Shift+右键`** 拖动平移视角；鼠标悬停卡牌或规则书按住 **`Alt`** 键即可高清放大预览。
> - **小猪与吸附**：选中棋盘上的小猪按 **`F` 键**即可快速翻面切换「清醒 / 熟睡」状态；拖动小猪与计分标记时会自动吸附到 25 个格心与两侧 0–15 刻度上。
